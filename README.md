# 还我小说！

> 距离晚自习结束还有一段时间。你借来的《两仪道》被班主任没收了。  
> 你不想欠朋友人情，于是决定从教室后门溜出去，把它拿回来。

一个 **2D 校园潜行 + 回合制嘴炮卡牌** 短篇游戏。四个场景、四个 Boss、两种结局。

## 玩法

- **潜行**：躲过 Boss 的视线，利用课桌、隔间、书架、窗帘和投掷物。被看到或发出声音都会累积警觉条。
- **嘴炮**：一旦被发现，就进入回合制卡牌战斗。Boss 的台词有隐藏的“道理 / 感情 / 事实”类型，回应牌也有同样的类型。
- **克制**：讲道理克谈感情，谈感情克摆事实，摆事实克讲道理。克制 ×1.5，同类型 ×1，被克 ×0.5。
- **限时**：清空 Boss 的坚定值；教导主任的脚步走完，你就会被拎回座位。
- **成长**：用“面子”升级体力、速度、潜行、口才。牌组固定 9 张，每场带 6 张，击败 Boss 后可以调整。
- **两种结局**：全程零战斗的“无声归还”，或者被十一发现、打赢嘴炮后的“当面归还”。

## 操作

**电脑**

- `WASD` / 方向键：移动
- `Ctrl` / `C`：蹲伏
- `Shift`：冲刺
- `Space`：闪避
- `E`：互动 / 躲藏
- `F`：扔橡皮
- `1` / `2` / `3`：嘴炮出牌
- `Esc`：暂停

**手机**

- 左侧虚拟摇杆移动
- 右侧动作键：扔、蹲、冲、闪、互
- 嘴炮战直接点卡牌
- 暂停菜单 / 游戏右上角可进入“调整按键”，拖动按钮并保存，位置会保存在本机
- 推荐横屏

## 开发

```bash
pnpm install
pnpm dev
pnpm build
pnpm preview
```

技术栈：**Phaser 3 + Vite + TypeScript**，纯 2D Canvas，角色和场景为自制 SVG，音效由 Web Audio 程序化生成。没有运行时 AI，没有付费素材。

## 部署

推送到 `main` 后，GitHub Actions 会自动构建并发布到 GitHub Pages。  
仓库 Settings → Pages → Source 选择 **GitHub Actions**。

## 制作
